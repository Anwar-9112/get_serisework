# Frontend Mentor - Blog Preview Card

This is my solution to the [Blog preview card challenge](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS) from Frontend Mentor.

## Overview

### The challenge

The challenge was to build a blog preview card and make it look as close as possible to the provided desktop and mobile designs.

Users should be able to:

- See hover and focus states for interactive elements.
- View the layout correctly on different screen sizes.

### What I learned

This project helped me improve my understanding of responsive layouts and CSS.

Some of the main things I learned were:

- How to use Flexbox to center and align content.
- How to use media queries to adjust a design for mobile screens.
- How margin and padding affect spacing between elements.
- How `border-radius` and `overflow: hidden` work together to create rounded image corners.
- How `object-fit: cover` makes an image fill its container while maintaining its aspect ratio.
- How to use Git and GitHub to manage and publish my project.

### Continued development

In future projects, I want to improve my responsive CSS, write cleaner and more maintainable styles, and become more accurate when translating Figma designs into code.
